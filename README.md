# Page Header Bookmarks

为 Obsidian 的**页首**（每个面板顶部的标题栏 —— 即 Commander 插件所指的 "Page Header"）添加一个书签图标按钮。点击后弹出浮层，展示核心插件「书签」(Bookmarks) 中的全部书签。

## 功能

- 在**每个面板的页首**（⋯ 更多选项按钮左侧）注入书签图标，所有笔记/视图页首均可用；
- 点击图标 → 在图标下方弹出书签浮层（内容来自核心插件「书签」）；
- 浮层内展示全部书签（核心插件支持的全部类型）：文件、文件夹、分组、搜索、URL、图谱；
- 数据来源多路兼容：优先读取运行中的书签插件实例，兜底直接读取 `.obsidian/bookmarks.json`，新旧版本数据结构均可识别；
- 点击行为：
  - **文件书签** → 打开该文件（含书签内保存的标题/块定位），并关闭浮层；
  - **文件夹书签** → 在浮层内展开/收起文件夹的实际内容（子文件夹可继续展开），**不会关闭浮层**；
  - **分组** → 展开/收起分组内的书签，**不会关闭浮层**；
  - **搜索书签** → 打开搜索面板执行该搜索，并关闭浮层；
  - **URL 书签** → 用浏览器打开链接，并关闭浮层；
  - **图谱书签** → 打开图谱视图（尽量恢复保存的视图选项），并关闭浮层；
  - 右键或触屏长按弹菜单、拖拽移动**不会**触发普通点击（打开/展开）；长按弹菜单或拖拽结束后，紧随其后的合成点击会被自动忽略；
- **右键 / 触屏长按菜单**（按书签类型提供不同菜单项）：
  - 文件书签：打开 / 新标签页打开 / 复制链接 / 重命名 / 移动到分组… / 删除；
  - 搜索书签：打开 / 新标签页打开 / 复制查询 / 重命名 / 移动到分组… / 删除；
  - URL 书签：打开 / 新标签页打开 / 复制链接 / 重命名 / 移动到分组… / 删除；
  - 图谱书签：打开 / 新标签页打开 / 重命名 / 移动到分组… / 删除；
  - 文件夹书签：展开 / 重命名 / 移动到分组… / 删除；
  - 分组：展开/收起、重命名、移动到分组…、删除（删除前二次确认，并提示将一并删除的组内书签数量）；
  - 「移动到分组…」弹 Fuzzy 分组选择器（层级路径，可模糊搜索），支持移动到顶层或任意分组（排除自身/后代）；
- **拖拽移动**（鼠标与触屏均支持）：拖到分组行中间 = 移入该分组；拖到分组行上/下边缘（25%）或普通行上/下半 = 同级排序（before/after）；拖到列表空白处 = 移出分组到顶层；拖动中有行高亮/插入线、列表边缘自动滚动；拖拽有位移阈值，不会与滚动/点击冲突；触屏长按约 0.4s「拿起」后可拖动，继续按住不动约 0.6s 弹菜单；
- **数据写回**：所有修改直接写回核心书签数据 —— 优先走书签插件实例（改 `items` + 保存），兜底直接写 `.obsidian/bookmarks.json`（写前自动备份 `.bak-phb`、写后重读校验、失败自动回滚并提示）；无法写入时自动降级为只读模式（菜单只显示打开/复制等只读项，不提供拖拽）；
- 关闭方式：点击浮层**外部任意位置**、按 `Esc`、点击浮层右上角 ×、再次点击页首书签图标；
- 若核心插件「书签」未启用，浮层内提供一键启用按钮；
- 已删除文件的无效书签**不显示**（与核心书签视图行为一致）；
- 文件/文件夹书签显示**书签中记录的标题**（未设置时回退为文件名）；若某文件夹本身被书签，则其内部文件不再作为独立书签重复显示，只在展开该文件夹时可见；

## 安装

### 方式一：BRAT（推荐）

1. 安装并启用 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件；
2. 运行命令 `BRAT: Add a beta plugin for testing`，输入：
   ```
   https://github.com/night-system/obsidian-page-header-bookmarks
   ```
3. 启用插件 **Page Header Bookmarks**。

### 方式二：手动安装

1. 到 [Releases](https://github.com/night-system/obsidian-page-header-bookmarks/releases) 下载最新版的 `main.js`、`manifest.json`、`styles.css`；
2. 将三个文件放入你的库目录下的 `.obsidian/plugins/page-header-bookmarks/`；
3. 在「设置 → 第三方插件」中启用。

## 使用

打开任意笔记，在面板顶部页首的右侧（⋯ 菜单按钮左侧）即可看到书签图标：

```
┌─────────────────────────────────────────────┐
│ 笔记标题            …    (⋯ 菜单)            │
│                          🔖 ← 书签按钮       │
└─────────────────────────────────────────────┘
```

点击 🔖 弹出书签浮层，按上述行为操作即可。

> 依赖核心插件「书签」(Bookmarks)。书签数据即核心插件的数据；本插件支持**右键/长按菜单**与**拖拽**管理书签（打开/复制链接/重命名/删除/移动到分组/同级排序），**修改前自动备份**，写入失败自动回滚并提示；无法写入时自动降级为只读。

## 兼容性

- Obsidian ≥ 1.5.0（桌面端 / 移动端均可）
- 无其他外部依赖
- 写回数据时优先使用核心书签插件的实例 API（`items` + `onItemsChanged`/`saveData`，均带特性检测），缺失时自动回退为直接写数据文件（旧版本数据结构 `groups` 数组按原形状写回），仍不可写时降级为只读模式
